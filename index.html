Projects

Maria Carrillo AI & Machine Learning Club

Real-Time AI Object Detection

A real-time object detection system running on a Raspberry Pi with a Hailo AI accelerator and a YOLO model. The app draws a box around every person and object it sees in a live camera feed, along with a confidence score for each.

We built it through the AI & Machine Learning Club and demoed it live at a community expo, where visitors walked up and watched themselves get detected on screen. It was a hands-on way to show people what computer vision can do.
